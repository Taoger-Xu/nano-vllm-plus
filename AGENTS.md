# Project Coding Guidelines

This project follows the installed `karpathy-guidelines` skill.

- Think before coding: state assumptions and surface ambiguity.
- Prefer the smallest implementation that directly solves the requested problem.
- Make surgical changes and preserve existing style and behavior outside the request.
- Define verifiable success criteria and run focused checks before finishing.
- Remove only unused code introduced by the current change; leave unrelated cleanup alone.

For changes to this repository, every modified line should trace directly to the task.
